# تقييم الجمهور المباشر (نجوم 1–5)

صفحتان:
- `/`  صفحة التصويت (للجوال، يفتحها الحضور بمسح الـ QR)
- `/screen.html`  شاشة العرض (QR + المتوسط + توزيع النجوم لايف)

## النشر على Cloudflare (مرة وحدة، تقريبًا ١٠ دقايق)

1) ثبّت الأداة وسجّل دخول:
   npm i -g wrangler
   wrangler login

2) أنشئ قاعدة البيانات:
   wrangler d1 create stage-rating
   انسخ `database_id` اللي يطلع وحطه في ملف wrangler.toml

3) أنشئ الجدول:
   wrangler d1 execute stage-rating --remote --file=schema.sql

4) انشر:
   wrangler pages deploy

5) حدد رمز المشرف (للتصفير):
   wrangler pages secret put ADMIN_PIN --project-name stage-rating

## الاستخدام
- افتح على شاشة المسرح:  https://<مشروعك>.pages.dev/screen.html?s=lecture1&t=عنوان المحاضرة
- `s` اسم الجلسة (لكل محاضرة اسم مختلف، نتائجها منفصلة)، و`t` العنوان الظاهر (اختياري)
- الحضور يمسحون الـ QR ويقيّمون. يقدرون يغيّرون تقييمهم، وكل جهاز له صوت واحد.
- زر «تصفير النتائج» أسفل الشاشة يحتاج رمز المشرف.

## ملاحظة
منع التصويت المكرر يعتمد على الجهاز (المتصفح). أحد يقدر يتحايل بمتصفح خاص أو جهاز ثاني؛ مناسب لجمهور محاضرة وليس لانتخابات.
